## 使用说明

1、目前只有windows系统版本。

2、在Releases下载对应压缩包解压到非C盘系统目录，运行`viseek.exe`即可。

3、本软件本体为了模拟web环境会在本地启动web服务，不会向任何外部服务发送信息，请各位监督。

4、软件本身绿色免费，可商用，具体版权与使用许可请往下查看。

5、遇到问题与提供建议请通过issue进行。

## 版本说明

目前版本是流程完整的，但是存在许多的bug与优化点，权当体验版本，暂不保证数据的兼容，请各位做好相关的数据备份。
